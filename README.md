# Loopline

Place sounds on a timeline and let it loop. A single-page step sequencer that installs as an app and works offline.

**Play it:** https://dmarkscouk.github.io/loopline/

No build step: `index.html` is the whole app, `sw.js` caches it for offline use, and `manifest.webmanifest` plus `icons/` make it installable.
